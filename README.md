# Quizz App

Application de quiz JavaScript développée dans le cadre d'exercices de formation sur la Programmation Orientée Objet (POO).

🔗 [Voir le site en live](https://gclaude21.github.io/Quizz-App/)

## Fonctionnalités

- Questions à choix multiples
- Calcul du score en temps réel
- Affichage du résultat final
- Progression affichée question par question

## Concepts abordés

- Classes ES6 et constructeurs
- Héritage et méthodes
- Manipulation du DOM
- Gestion des événements

## Structure

- `Question` : classe représentant une question avec ses propositions et sa réponse
- `Quiz` : classe principale gérant la logique du quiz, le score et le rendu

## Technologies

- HTML
- CSS
- JavaScript (ES6)
